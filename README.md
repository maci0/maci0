# Marcel Wysocki

Systems engineer at Red Hat, based in Singapore. I work where software meets the metal: container runtimes, Kubernetes internals, GPU inference, and the occasional 20-year-old game binary.

## What I build

**Containers and infrastructure**
- [docker-systemd-unpriv](https://github.com/maci0/docker-systemd-unpriv) — running systemd in unprivileged containers, before it was easy
- [katamaran](https://github.com/maci0/katamaran) — live migration for Kata Containers
- [gvisor](https://github.com/maci0/gvisor) — macOS port of Google's application kernel
- [vmetal-openshift](https://github.com/maci0/vmetal-openshift) — full virtual baremetal OpenShift lab: Redfish BMC emulation, bonded NICs, split-DNS, one data-driven Ansible topology

**LLM inference, from scratch**
- [agave](https://github.com/maci0/agave) — LLM inference engine written in Zig
- [beam](https://github.com/maci0/beam) — pure-Python subset of Ray's API that gets vLLM running distributed across nodes in ~1,400 lines, NVIDIA and AMD

**Reverse engineering**
- [openmiles](https://github.com/maci0/openmiles) — open reimplementation of the Miles Sound System for classic games
- [rebrew](https://github.com/maci0/rebrew) — compiler-in-the-loop decompilation workbench for binary-matching reversing
- [europa1400-networkfix](https://github.com/maci0/europa1400-networkfix) — fixing multiplayer in a 2001 game the vendor abandoned

## Languages

Go, Zig, Python, C, Shell. Zig for things that must be fast, Python for things that must exist by Friday.
